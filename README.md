## 📌 Descripción del Proyecto

Aplicación web interactiva y generador de prueba para el **Simulacro Comprensivo de Matemáticas 2026**. Contiene 60 ítems de selección única transcritos fielmente con gráficos vectoriales (SVG), tablas de datos, opciones de respuesta, retroalimentación formativa inmediata y una **Hoja de Respuestas** sincronizada en tiempo real.

### ✨ Características Principales

- **Portada Institucional Oficial:** Con datos del MEP, Liceo Rural San Isidro, ficha del estudiante, especificaciones de la prueba (60 ítems / 60 pts), rubro de calificación e instrucciones generales.
- **Calificación Interactiva:** Al pulsar *«Comprobar»*, el sistema evalúa la prueba en tiempo real, indica claves correctas con explicaciones razonadas y actualiza la calificación y condición del estudiante en la portada.
- **Exportación / Impresión en PDF de Alta Calidad:** 
  - La portada ocupa limpiamente la **Página 1**.
  - A partir de la **Página 2**, el encabezado institucional oficial se repite en el borde superior de cada página del PDF (`display: table-header-group`).
  - Saltos de página inteligentes (`break-inside: avoid`) para que ninguna pregunta o gráfica quede cortada.
- **Hoja de Respuestas:** Modal interactivo con burbujas de selección (A, B, C, D) sincronizado con el cuestionario.
